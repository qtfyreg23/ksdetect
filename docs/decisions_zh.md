# 决定记录（Decisions Log）

记录那些经过深思熟虑做出的决定，未来的实验不应在没有事先讨论的情况下
悄悄推翻它们。只追加，不删改。

---

### D1 —— 项目从零重建；结论不沿用，工程经验沿用
时间：项目重启时。上一个项目版本的具体研究结论（FFN 与 Residual 的
强弱对比、哪一层是"峰值层"、H1/H2/H3 假设链条）**不会**作为既定假设
带入这个代码库——如果这些问题再次出现，必须重新从数据中推导。工程层面
的经验教训（见 `known_issues.md`）则会被沿用。

### D2 —— 生成前（pre-generation）和事后（post-hoc）两种设定都在
### 大范围扫描（wide scan）的研究范围内
上一个项目是在追逐某个 SOTA 基准的外部压力下放弃了"生成前"这个框架，
而不是因为数据证明这个方向行不通。在第一阶段的大范围扫描中，
`stage`（pregen/posthoc，生成前/事后）是一个自由变量，而不是提前就
定好的。

### D3 —— 模型：LLaMA-3.1-8B-Instruct，固定本地路径
`/autodl-fs/data/Llama-3.1-8B-Instruct`。不会针对每个实验重新讨论；
如需更改，只能通过在决定记录中新增一条明确的条目来完成。

### D4 —— 环境：conda，Python 3.10，PyTorch 2.4.1（CUDA 12.1）
选择这个版本是为了对常见的 AutoDL GPU 镜像有较好的兼容性。如果服务器
实际的 CUDA 驱动版本对不上，应该把 `torch` 重新固定为匹配的 wheel
版本（从 pytorch.org 获取），而不是把版本号放宽成区间——具体说明见
`environment.yml` 中关于这一点的注释。

### D5 —— 所有面向论文发表的图表一律仅使用英文，通过 `core.viz` 生成
目标发表渠道是国际期刊/会议。没有例外，也不允许按实验单独开后门。
参见 `core/viz/style.py` 中的 `assert_ascii_only`。

### D6 —— 服务器上的项目目录
`/root/autodl-tmp/ksdetect`。配置文件和 README 中的所有路径都是相对
于这个根目录的。
